# Deze map in Obsidian zetten

De map **Klantenkaart** is een kant-en-klare Obsidian-notitieset over het project.
Zo krijg je hem in je kluis:

1. Haal de repository op, of download alleen de map `obsidian/Klantenkaart` via
   GitHub.
2. Sleep de map **Klantenkaart** in je Obsidian-kluis. Waar je hem zet maakt niet
   uit — Obsidian vindt de onderlinge links zelf.
3. Open `Klantenkaart.md`. Dat is de hoofdnotitie; van daaruit hangen alle andere.

De schermafbeeldingen staan in `Klantenkaart/afbeeldingen/`. Verplaats die map mee,
anders zie je alleen kapotte plaatjes.

> [!tip] Twee instellingen die helpen
> - **Instellingen → Bestanden en links → Nieuwe links maken als: relatief pad** —
>   dan blijven links werken als je de map later verplaatst.
> - De notities gebruiken callouts (`> [!warning]`) en frontmatter. Allebei werken in
>   Obsidian zonder plug-ins.

## Wat erin zit

| Notitie | Waarover |
|---|---|
| `Klantenkaart` | Hoofdnotitie: stand van zaken en alle links |
| `Wat het doet` | Functionaliteit, scherm per scherm |
| `Online zetten` | Het Vercel-stappenplan met de twee valkuilen |
| `CSV-import` | Hoe herimporteren werkt zonder dataverlies |
| `Kleurgrenzen` | Groen/oranje/rood zelf instellen |
| `Beveiliging` | Wat beschermd is en wat niet |
| `Beslissingen` | Waarom het is zoals het is |
| `Openstaande punten` | Wat er nog moet gebeuren |
| `Technisch overzicht` | Architectuur, commando's, bestanden |
| `Logboek` | Hoe dit tot stand kwam, inclusief de missers |

## Waarom dit als bestanden komt en niet rechtstreeks

Er is geen Obsidian-koppeling beschikbaar in deze sessie, en Obsidian werkt sowieso
met bestanden op je eigen computer — niet met een dienst waar iets van buitenaf in
kan schrijven. Deze map is dus de enige correcte manier waarop dit bij jou terecht
komt.

> [!important] Deze notities zijn het geheugen, niet ik
> Een volgende sessie begint blanco: van dit gesprek blijft niets hangen. Wat hier in
> de bestanden staat en wat in de repository zit, is alles wat er bewaard blijft.
> Houd de notities dus bij als er iets verandert — zeker `Openstaande punten` en
> `Logboek`.
